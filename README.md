# glossedByRidhi 💅

A premium nail-art website for Ridhi, a nail artist. Visitors can browse nail designs, explore services, shop nail-care products, and book an appointment through an elegant, mobile-friendly interface.

## GitHub About

Premium nail-art website built with React, Vite and Framer Motion — featuring nail designs, services, shopping, cart and appointment booking.

## Features

- Sticky navbar with blur effect on scroll
- Animated mobile navigation menu
- Hero section with floating nail image and decorative animations
- Services section with prices and booking buttons
- Nail design collection with category filters
- Favourite designs and design details modal
- Shop section with product search, ratings, discounts and wishlist
- Slide-out cart drawer with quantity controls and total
- Cart and wishlist data saved in localStorage
- Appointment booking form with validation
- FAQ accordion
- Newsletter signup
- Toast notifications
- Responsive design for mobile, tablet and desktop

## Tech Stack

- React
- Vite
- JavaScript
- Framer Motion
- Lucide React
- React Router
- Context API
- CSS
- localStorage
